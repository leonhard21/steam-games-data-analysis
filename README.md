# Steam Games Data Analysis

Analise exploratoria de dados de jogos do Steam, feita em Python. O script le os dados de um arquivo CSV e gera graficos interativos com Plotly.

## Tecnologias utilizadas

- Python
- Pandas
- Plotly
- Dash

## Pre-requisitos

Python 3.8+ instalado e disponivel como python no PATH.

## Como executar

1. Clone este repositorio
2. Instale as dependencias: pip install -r requirements.txt
3. Execute: python analise.py (ou use o script run.ps1 no Windows)
